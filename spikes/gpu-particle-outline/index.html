GPU 粒子 + 程序化纹理 + 多段线轮廓 · 研究原型

一个 instanced draw call 画完整个角色：quad = 部件，片元里算多段线 SDF 轮廓 + 程序化 pattern + 调色板量化 + 运动驱动 rim/glint。骨骼在 CPU 算每部件 pos/rot（方案 §6-1），斗篷/羽饰用弹簧滞后（§6-2）。

轮廓是手工多段线（logo 式折线），pattern 为条纹/棋盘/噪点/鳞片/金属渐变五类，全部颜色走 8 档调色板查表；硬边靠 discard（alpha test），无 blending、无深度，层序由 CPU 按 layer 排序后单次 instanced 绘制。细节与结论见同目录 RESEARCH.md。
