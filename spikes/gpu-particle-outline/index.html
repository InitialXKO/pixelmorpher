GPU 粒子 + 程序化纹理 + 多段线轮廓 · 研究原型（mask 烘焙版）

架构口径：SDF 只是生成 mask 的中间工具——加载时在 CPU 把多段线距离场阈值化成像素 mask（描边/明暗/rim/高光候选一次烘焙进图集），片元只做纹理采样 + 调色板查表（pattern 程序已在烘焙期编译进 mask），逐像素成本 O(1)、与线段数无关。一个 instanced draw call 画完整个角色；骨骼在 CPU 算位姿（方案 §6-1），斗篷/羽饰弹簧滞后（§6-2）。

每个部件的外观是一段 pattern 程序：由枚举形式组合（光照 = 平涂/纵向渐变/横向渐变，描边 = 暗色 1px，rim = 朝向边缘带，表面 = 条纹/棋盘/噪点/鳞片），烘焙期编译成 mask（R = 调色板档位、255 = 透明；G = glint 候选）。运行时只剩采样、glint 点亮与查表。光照/描边/rim 因此都是离散形式而非连续公式，改外观 = 改程序组合，不改着色器。细节与结论见同目录 RESEARCH.md。
