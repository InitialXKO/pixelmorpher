# 机甲模式库：分层清册与 DAG（v1，以腿 spike 为样本抽取）

层序（用户定）：**算子 → 模式 → 模式组合 → 模式库 DAG → IR → 生成器**。
本文是第一步的交付：把 `gen-legs-v29.mts` 里纠缠在一起的东西按四层拆清、接口定死。
样本是腿，但分层按全机甲设计：新部位照此入庫，不再写整文件。

## L0 算子层（只认几何与色彩，不认部位）

### 框架与随机
| 算子 | 接口 | 说明 |
|---|---|---|
| segFrame | (a, b) → {ux, uy, px, py, len} | 两点定段坐标系（轴向/法向） |
| bumpAt | (t, c) → 高斯权重 | 隆起剖面 |
| bezier | (p0, p1, p2, t) → 点 | 二次贝塞尔采样（线缆用） |
| mulberry32 / hash2 / vnoise / vnoise1 | seed → 确定性随机/噪声 | 全库唯一的随机源，种子制 |
| ramp / mix / shade2 / quant | 颜色 × 系数 | 色彩算子；quant 是平坦色阶量化（面式着色的根） |
| formProfile | u → 剖面系数 | 板面形态剖面 |

### 形状算子（形状测试 → [命中, u, v]，u/v 是部件局部参数场）
| 算子 | 形状 | 备注 |
|---|---|---|
| plateTest | 段板：t 区间 + 宽收分 + 隆起 + 端切角 + 四角切角 + 侧边台阶 | 板的全部形态语言都在此一算子内 |
| polyTest | 任意多边形（包围盒 uv） | 护板/块/楔等 |
| blockPoly | 切角八边形多边形构造 | 块的统一外形：块长什么样由它定 |
| discTest | 12 边刻面盘（平边 0.966r、棱角 r） | 盖帽/法兰/端盘共用 |
| lineTest | 圆头杆（半径 r） | 杆/筒/管/脊（已删）共用 |
| silQuad | 包络标记（体积规格） | 不是部件：只写 sil，是组合层给的体积上限 |
| fillShape / markSil | 执行算子：把形状测试写进 owner/u/v / sil | 一切模式落笔的唯一通道 |

### 着色算子（渲染 pass，按 owner/u/v 场工作）
- **基色分面**：按 kind 分场着色——板=横向四带平涂+折线+面板线网+端平带；盘=扇区平坦分面；筒=偏前高光剖面；杆=五段横剖面。**着色单位是面，不是像素场**（v11 定版）。
- **调色拉伸 / 分族明度**：全局对比拉伸、逐族明度带对齐。
- **投影**：按 owner 序号（绘制序=前后）在身后部件落影。
- **边面组**：盘缘侧壁（四周 3px 厚度带）、斜面带（边界亮唇/暗唇）、凹陷暗影（接缝下影）——「块有厚度」的渲染根。
- **棱线高光**：每块上/前缘 1px 亮线（并入边面组执行）。
- **做旧组**：啃边、划痕、磨损斑、定向磨损（凸缘掉漆偏置/螺栓下锈流挂/螺栓旁刮痕）、底部积尘。全部**定位**生成（按边界/螺栓/位置），非均匀噪点（v18 定版）。
- **盖章组**：点阵字（FONT+drawText，带 owner 校验）、标志图形（菱/十字/三角/横杠）、人字纹、涂装条纹、仪表窗、趾前端面、铆钉、信号灯、警示三角。盖章一律归板/归件（v29 定版：不跨块）。
- **收尾组**：描边、接地影（剪影外）、末端清扫（无主像素清回透明——漏黑定版的执行者）。

## L1 模式层（部件级构造：锚点 + 参数 → 部件实例集）

|---|---|---|---|---|
| 结构核 | 关节链 [(a,b,ra,rb)] | 半径剖面、coreScale | fillShape（链距离场） | frame 实例 ×1（跨关节整件） |
| 框梁 | 段规格 | 宽比 0.82、隆起 | plateTest | frame 实例（框主导族） |

| 波纹套 | 膝后两段偏移 | 环数 5、半径递增 | lineTest | frame 实例 ×5 |

| 足型·爪 | 踝点 | 基座 + 前趾两节 + 后趾两节（转角/尺寸表） | polyTest(blockPoly) | foot 实例 ×5 |
| 足型·垫 | 踝点、toeX | 基座宽平 + 前段块 + 跟块 | polyTest(blockPoly) | foot 实例 ×3 |
| 靴筒整流罩 | 踝前上 | 96×30 块 | polyTest(blockPoly) | plate 实例（blocks/shoe 共用） |
| 足底件 | 踝→toeX | 只留底边 2px | polyTest(blockPoly) | frame 实例 |
| 贴纸系统 | 板/件锚（编号=首板扫描落点） | decalKind、种子选字/选形 | 盖章组（owner 校验） | 编号/CAUTION/徽记/双斜杠/灯串 |

模式的共同纪律（历轮定版，入庫即带）：形态由模式自身参数定、不由包络/缺口反推；块间叠压相接不留孤岛；贴纸归板；种子决定逐件差异、不用全局统一样式。

## L2 组合层（部位与整机：只选模式、给锚点、定参数）

- **腿组合**（现 `layout`）：骨骼锚点 = 髋/膝/踝 + toeX（由 bend/ankleShift/topology 定）；
  体积规格 = 段宽表（thigh 110→84、shin 94→64，×wScale）+ 隆起 + 关节盘 + 足包络 → silQuad 标记；
  实例序列（=绘制序=前后序）：结构核 → 框梁（frameHeavy） → 线缆 → 段板组×2 → 足型 → 护板 → 膝盖帽/小盒 → 中型构件 → 活塞 → 关节簇×3 → 波纹套 → 贴纸锚。
- **变体规格 LegSpec**（组合级参数）：topology、scheme（配色族）、seed、bend、wScale、lift、ankleShift、guardOff、detail、frameHeavy、shellMode、wear、camo、decalKind、cableTint、coreScale、footType。其中 footType/coreScale 等下沉到模式级，scheme/seed 是全局级。
- **双腿/阵列组合**（现 renderPair/formation）：同一腿组合实例化两次（近/远），远侧压暗去饱和后移——整机组装的雏形：组合之上再组合，靠层序与调色区分前后。

## DAG（依赖图）

```
L0 算子 ── 形状: segFrame/plateTest/polyTest/blockPoly/discTest/lineTest/silQuad
       ── 执行: fillShape/markSil
       ── 着色: 基色分面/边面组/做旧组/盖章组/投影/描边/清扫 …
              │
L1 模式 ── 结构核 ────────┐
       ── 框梁 ───────────┤
       ── 段板组 ─────────┤ （板本体+衬边+面板线+铆钉锚）
       ── 关节簇 ─────────┤ （法兰/盖帽/壳体块/毂块）
       ── 护板/裙板/膝盖帽/小盒/中型构件/活塞/线缆/波纹套
       ── 足型 ×4 ────────┤ （厚块/鞋/爪/垫）
       ── 贴纸系统 ───────┘
              │
L2 组合 ── 腿组合（骨骼锚点 + 体积规格 + 实例序 + LegSpec）
       ── 双腿/阵列组合
              │
（下一步）整机组合：躯干组合 + 头 + 肩 + 臂组合 + 腿组合 + 组装布局
              │
IR ── 角色 = 骨骼布局 + 部位→模式实例与参数 + 配色族（下一步定义）
              │
生成器 ── 读 IR → 按序实例化模式 → 执行算子 → 像素（下一步改造）
              │
下游（库外接口）── 产品表面模式：结构侧产出 owner 图 + u/v 参数图，
                  既有 49 个表面算子消费此三图（分件场源缺口在此对接）
```

逐模式依赖（节选关键边）：段板组 → plateTest/fillShape/基色分面/边面组；关节簇 → discTest/blockPoly/基色分面（盘扇区）；
足型 → blockPoly/边面组/盖章组（端面）；贴纸系统 → 盖章组 + 段板组（落点归属）；投影/做旧组 → 全部模式（横切，按 owner 工作）。

## 算子层扩展纪律（用户定，2026-11-06）

模式/组合层在建新部位时遇到现有算子表达不了的形状或着色，**当场在 L0 新增算子**：
定死接口（输入/输出/uv 语义）、写进本清册、模式只准组合算子。禁止在模式里内联一
次性几何或着色绕过算子层——一次性的写法沉淀不下来，新部位再遇到同样的需要还会
再发明一遍。算子层是活的，随部位建设持续生长。

## 补册一：新模式入庫（2026-11-06，头/躯干/肩/臂/手/车体/背包/挂载）

### 入庫纪律（方法，与算子扩展纪律并列）
- **跨样本反复出现才入庫**：一条模式要能指出它在哪些样本身上重复出现；只在
  一台身上成立的，降级为族变体槽或实例贴花，不进定版。
- **不取数字**：比例尺寸是实例参数、不是模式。模式只记构造关系（哪几件、怎么
  拼、变体槽在哪），尺寸由构造关系与组装现场带出。
- **证据分级如实标**：构成定版（构件清单跨样本成立）与元素配方（像素级画法已
  对读）分开标；只到构成级的，不许冒充配方已定。

## 补册二：元素配方（2026-11-06，逐元素放大对读）

### 带框横槽栅 framedGrille（跨部位反复出现的同一元素）
构造：外框（比周围板深一档的边框盒）+ 内里 3 条横向暗槽、槽间亮脊。出现在：
橄榄盔侧（耳上）、heavy 胸侧（槽带强调色边）、powersuit 背包、主战车体侧。
→ 定为共用元素算子：给框 rect + 槽数，渲染期按归属落栅。腿系统的通风栅/仪表
窗与它是同一配方（仪表窗是其带窗面变体）。

### 头部元素配方
- **眼**：眉檐之下的**暗凹座**里放发光核，两种形：缝（细横线，heavy）/ 楔
  （前亮后收的光斑，橄榄）。禁式：在平脸上直接贴一条亮线（v1/v2 的错）。
- **眉檐**：盔体前上的一块板向前出檐，眼带在檐下凹进去一档——面廓三段的第
  一段与第二段就是檐与凹。
- **口格栅**：两式——肋管式（橄榄：金属肋纹短管自颊斜出至颏，颏块前突）/
  颏栅式（heavy：颌下横槽栅）。共同点：颌部比眼带平面更前凸。
- **耳盘**：颌轴处的圆盖 + 内里一小道标记（powersuit 最清楚）；橄榄耳位被
  带框栅占（同位置二选一：耳盘或侧栅，二者都是颌轴侧件）。
- **顶部附属**（变体槽的配方）：额角 = 眉上向前楔形刺板、根粗尖细；鞭天线 =
  盔后顶细杆、分节色；V 角 = 两片薄板后掠。

### 躯干元素配方
- **胸侧栅**：framedGrille 落在胸主面板的后侧中段；heavy 式槽边带强调色。
- **腰带**：胸与骨盆之间的整圈暗带（内框色）+ 前面一小块扣盒（金属）。
- **骨盆前带**：骨盆前面下沿一条强调色横带（橄榄在场；作贴花级、非必需）。
- **裙甲**：挂板自骨盆下缘斜出（前裙近垂、侧裙外张），下沿带条纹贴花（归板
  盖章，同腿裙板）。

## 补册三：跨部位通用构造模式（自腿部抽取，全部位通用）

列 = gen-mecha/gen-walker 的执行情况，出库时逐条对）。
