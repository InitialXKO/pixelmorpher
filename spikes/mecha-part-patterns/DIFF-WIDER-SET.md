## 差距模式（按出现张数排序，D1–D10）

### D1. 腿不是一种拓扑，是四个族（12 张里 11 张不在 v3 的族内）
v1 结论“两段链 + 三盘是主流”只在重型双足族内成立。更广集分四族：
- A 重型双足（MBT / fortress / mecha-side）：v3 的目标族，最接近。
- B 反关节细腿（railgun；scout 已在 v1 内）：细长胫、裸露深色骨架杆、
  小关节盘、爪形足。v3 无“裸露骨架”模式，板子盖满全身。
- C 多腿柱腿（missile / command / aa / engineer / fortress / quad）：
  短粗叠块腿、每块接缝处一个大盘、宽扁掌足、同一单元重复 4–6 条。
  v3 的长腿比例在此族全错；重复本身就是该族的模式。
- D 人形动力甲（powersuit / agile）：修长、大曲面光壳、膝盘小而暗、
  藏在壳后、长条强调色、靴形足。
- E 蜘蛛/兽形（spider / beast）：多节细腿、装甲是罩在黑色支杆上的壳、
  爪掌。
v4 动作：拓扑从一个“标准腿 + 开关”改成族参数（族 ∈ {A,B,C,D,E}，
每族自带段长比、宽度曲线、盘大小、足形）；先做 B 与 C，D 与 E 随后。

### D2. “关节一律大圆盘”是错的（反例：powersuit / agile / railgun / spider）
v1 的构件结论过度推广。大盘只属于 A/C 族；D 族膝关节是小暗关节，
基本被壳遮住；B/E 族盘小。v3 仍在髋/膝/踝三处放同样巨大的灰环，
在 D 族对照下直接出戏，且 v3 的盘是扁平灰环浮在板面上。
参考盘（MBT / fortress）：盘体与板同色系（橄榄盘、灰盘），有凸起同心
环 + 一圈螺栓点；v3 的盘是灰色、与板面脱节。
v4 动作：盘径与盘色改为族参数；盘改为“嵌进板缝”而非叠在板面；
盘面加凸起环 + 螺栓圈。

### D3. 足不是一块平板（12 张全数如此）
参考足一律是独立大构件：MBT 是带趾块的靴 + 踝盘压掌；quad/beast 是
带趾/爪的掌；powersuit/agile 是靴。v3 足是约 30px 高的扁 slab，无趾、
无跟、无踝结合。
v4 动作：足做成独立构件（掌 + 趾块/爪 + 跟），高度提到段宽的 0.8 倍
以上；踝盘压在掌上（v1 已有此条，v3 未落实）。

### D4. 板不是长矩形，是带大倒角的阶梯叠板（MBT / fortress / engineer / aa）
参考板是多边形：大倒角、上下板阶梯搭接、板缝是 6–15px 的深色豁口，
露出近黑内框。v3 板仍是长矩形 + 发丝缝；v3 的凹陷暗影只压了一档，
缝的“豁口感”没出来。
v4 动作：板形原语加倒角量与错位量两个参数；缝宽提到 4–8px（按画布
比例），缝内填近黑内框色而非板面暗色。

### D5. 活塞是斜跨关节的粗杆，不是贴边细线（MBT / engineer / missile）
参考活塞粗、斜跨关节（MBT 银杆斜跨膝约 45°）、常成对。v3 活塞贴腿
平行走、细、藏在板边，读作装饰线；副油缸同病。
v4 动作：活塞改为跨关节斜线（起止点锚在关节两侧的板上），筒径提到
段宽的 0.18 倍以上，杆给铬亮高光；每关节至少一根主活塞。

### D6. 细节密度是族参数，不是全局层数（agile / powersuit vs fortress / aa）
重型族细节密（通风栅、螺栓排、面板线全上）；D 族反其道：大面积光壳
+ 寥寥几条纵向强调线，几乎无螺栓/栅格。v3 全局加密度，在 D 族对照下
是反效果。v1→v3 “层数 × 词表量 = 复现度”的规律只在同一族内成立。
v4 动作：细节密度改为族参数（dense / clean 两档起步）；clean 档关掉
栅格/螺栓排，改加纵向强调色带。

### D7. 装甲是罩在骨架上的壳，骨架可以露出来（beast / railgun / spider）
B/E 族的板与板之间露出黑色支杆骨架，装甲是壳不是实心体。v3 只有板缝
里透一点内框色，没有“裸露骨架”这一层。
v4 动作：加一层“外露骨架”：在板间空隙画深色杆 + 小盘；B/E 族默认开启，
A 族关闭。

### D8. 贴纸/警示纹：位置、尺寸、留白三条全错（v3 实测缺陷）
- v3-leg-olive 与 v3-compare-mbt 上 "CAUTION" 被护板边缘截断（只剩
  CAUTIO），大腿编号 M-81 右侧出界。参考贴纸一律完整落在板内、四周留白。
- 参考警示条纹是宽带：missile 舱底一整条黑黄斜纹带、engineer 整板橙色
  斜纹、aa 小腿白色大 V 纹；v3 的橙色只是细折线。
v4 动作：贴纸排版先算板内包围盒再落字（超界自动缩小/换行，永不截断）；
警示纹改为宽带原语（带宽 ≥ 板宽的 0.25）。

### D9. 配色：双色壳与大块迷彩（powersuit / agile / command / missile）
v3 只有单色板 + 橙强调。D 族是双色壳（白/蓝、橙/白长条）；C 族迷彩是
大块斑（command / missile），不是 v2 的小斑点；aa 族有白色 stencil
标记（+、三角、V 纹）。
v4 动作：色板加第二主色（壳面双色）与迷彩块尺寸参数；stencil 词表加
+ / 三角 / V 纹。

### D10. 剪影：参考腿的轮廓是阶梯与隆起，不是直边（MBT / quad / fortress）
v3 腿的侧边基本是两条直线；参考大腿有臀部隆起（quad 的 haunch 最明显）、
板与板之间有台阶错位。v3 虽然把段加宽了（大腿 wA 98→110），但直边轮廓
仍让它读起来细长。
v4 动作：段宽曲线加隆起参数（中段外凸）；板间加错位量，剪影出阶梯。

## v4 建议顺序（按“一张图改动、多族受益”排）

1. D3 足 + D4 板形/缝宽：所有族共用，改动最小、视觉收益最大。
2. D8 贴纸不截断 + 宽带警示纹：这是 v3 图上肉眼可见的缺陷，先修。
3. D1 族参数 + D2 盘族化：先加 B（反关节细腿）与 C（多腿柱腿）两族。
4. D5 活塞斜跨 + D7 外露骨架：B/C/E 族共用。
5. D6 密度族化 + D9 双色壳/stencil：D 族与 C 族的面貌项。
6. D10 轮廓隆起/阶梯：收尾的剪影项。
