# 全部位参考分析（新模式与 IR 的依据）

样本：图库侧视机甲 17 张 + 后补 boss/载具图。方法沿腿例：逐部位看构件清单、块的
切分、比例锚点、族间差异。先立一个结构事实，再逐部位记。

## 0. 两种（半）角色原型

- **人形型**（mecha-heavy / mecha-agile / mecha / powersuit）：头 + 躯干 + 肩 + 臂
  （带手）+ 骨盆 + 腿，人形布局。
- **载具型**（walker-mbt / aa / railgun / command / artillery / missile / engineer /
  boss-piledriver / fortress / landship）：无头无臂——车体骑腿，武器与传感器是车
  体上的挂载件。
- **兽型**（mecha-beast / mecha-quad / boss-spider）：体壳 + 前部兽首 + 背部挂载，
  与载具共用「体壳」构造、头部另算。

推论：模式库按**部位**组织、原型决定启用哪些部位；IR 的角色 = 原型 + 骨骼布局 +
各部位的模式选择。腿是唯一全原型通用件（已完成）。

## 1. 头（人形专属）

构件：主盔块（整块，侧面一块大面 + 顶面）、面甲部（前侧的暗带/眼缝，眼是一条横
亮线或一个亮点）、颌块（下前方小块，与主盔间有缝）、角/天线（细杆 1–2 根，或壳
的 V 形角——两片薄板）、耳侧圆件（小盘/小筒）。
比例：头宽约胸宽 1/4–1/3，高约躯干高 1/3；头在整机里是小件。
位置两式：**嵌入式**（重型：头沉进胸腔、只露上半，下方被胸板护住）与**立颈式**
（壳：颈筒一节 + 头立于其上，可见下颌全貌）。
画法：与全身同——块 + 平面 + 缝；眼缝是唯一的发光件（强调色小面积）。

## 2. 躯干·人形

构件自上而下：胸板组（2–3 块大板：上胸一块大面 + 两侧/下方分块，板缝横向为主）、
胸侧散热栅（一组横槽，位置在上胸侧或肋部）、腹腰节（比胸窄 15–25% 的 1–2 块，
常露内框色）、骨盆块（横宽块，两侧与髋关节相接）、裙甲（挂在骨盆下缘的板：前裙
1 块 + 侧裙 1–2 块，可动感地斜挂，前裙常带人字纹/编号）。
比例：胸宽是全机宽度基准；躯干高（肩线→骨盆底）约与一条大腿段长相当。
族间差异：重型胸板厚、大板少分块、腰几乎不可见；壳胸更窄、腰节明确、裙甲短小。

## 3. 车体·载具（代躯干）

构件：主箱体（二式：**平箱**——上下大面 + 侧板分面，如打桩机/要塞；**楔箱**——
前面大斜面 glacis + 顶面，如主战）、舱窗（前上方一小块深色玻璃 + 框，仅有人舱型
有）、侧裙板（沿体侧下缘的长板，遮腿根）、顶部接口面（平坦，供挂载）、底部腿座
（腿从体侧或体底长出，两式）。
细节语言：大面上就是面板线网 + 铆钉 + 编号 + 危险条纹带（boss 常见腰线一圈斜纹
带）；蜂窝/栅格等功能件嵌在大面里（发射器口、栅格窗）。
比例：车体宽可达腿展宽的 1.5–2 倍（ boss 更甚）；体高约腿长 1/2–2/3。

## 4. 肩（人形专属）

构件：肩壳大块（整块，顶面 + 侧面 + 前面三面可见，是上身最大的单块之一）、肩顶
附加板/装甲檐（部分机型）、内侧关节盘（与躯干相接处的小盘，被壳半盖）、上臂自
壳下缘长出。
比例：单侧肩宽可达胸宽的 40–55%（重型、壳都大肩）；肩高约当胸高一半。
族间差异：重型肩是方箱 + 顶灯/贴纸；壳肩是带弧面的整壳（但仍分面平涂，不是渐变
场）；动力装甲肩最小、近圆。

## 5. 上肢（人形专属）+ 手

段构造与腿同族（上臂/前臂各一段板组 + 肘关节簇 + 内框），差异在比例与端部：
上臂短粗（段宽/段长比比大腿大）、前臂常带一块大护板（比腿护板更常见、更大）。
端部（手）三式：**拳**（块状手套：掌块 + 指节前面，握物时与武器柄相接）、**爪**
（三指节爪，兽型/工程型）、**无手直连武器**（前臂末端即炮/工具座，工程型）。
肩→肘→腕的关节盘都比腿小一号，壳体块仍是块簇语言。

## 6. 背包（挂载，两原型通用）

三式：**炮筒组**（重型：2 根大筒并排 + 基座箱，筒身分段环带、口部制退孔）、
**翼组**（壳：1–2 片大薄翼板 + 翼根箱 + 喷口，翼是大板不是块，边缘有厚度面）、
**箱+喷口**（通用：箱体 + 1–2 个钟形喷口 + 短天线）。
侧视里背包露在躯干后上方，与头/肩争同一区，布局要留位。

## 7. 武器与传感器挂载（载具为主，人形手持另算）

- **炮塔**：小塔体（块）+ 塔顶传感器（球/小盘/短桅）+ 炮管（筒，带制退环带）。
- **主炮**：长筒组（基座筒粗、主筒细长、口部制退器一段粗节），可带供弹箱与线缆
  （线缆模式复用）。
- **蜂窝发射器**：箱体前面板上 N×M 管口阵列（圆口 + 内暗），是盖章/阵列型细节。
- **雷达**：刻面大盘（discTest 放大版）+ 桅杆（杆 + 横臂 + 顶球）+ 基座关节。
- **桅杆传感器**：细杆 + 多层横臂 + 小球/小箱，指挥型标志。
- 挂载点：车体顶面、车体侧面、背部三类锚点；挂载件自带基座块与主体相接。

## 8. 对模式库与 IR 的要求（本分析的产出）

新模式清单（按入庫顺序建议）：躯干组（胸板组/腰节/骨盆+裙甲）、头组（盔/面甲/
颌/角）、肩（关节簇放大变体，复用）、上肢段组合（复用腿段 + 前臂护板）、手型
（拳/爪/武器座）、车体组（平箱/楔箱二式 + 舱窗 + 侧裙）、背包三式、挂载组
（炮塔/主炮/蜂窝/雷达/桅杆）。
可能的新算子（遇到再按纪律扩展）：大板斜面形状（楔箱 glacis——plateTest 的段外
推广或新「斜面箱」算子）、管口阵列盖章（蜂窝）、钟形喷口剖面（lineTest 变体或
新算子）、翼板（薄板 + 边面）。
IR 必备字段由此定：原型、骨骼锚点表（颈/肩/肘/腕/髋/膝/踝 + 车体锚 + 挂载锚）、
部位→模式与参数、挂载清单、配色族。
