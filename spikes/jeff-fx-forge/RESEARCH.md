# 研究：Jeff-FX-forge 与模式库映射盘点

对象：https://github.com/Smidle/Jeff-FX-forge（克隆 HEAD `ec9c01d`，Godot 4.7 插件「Jeff FX 1.0.1」）。
问题（用户 2026-10-27 立）：它有哪些效果在模式库中**已有**、哪些**可组合出来**、哪些**可变相实现**、哪些**可加入模式库**、哪些**需要新算子/子模式**。
方法：对方 82 款逐文件读实现（不采信 README 宣传语）；我方以动态图案参数面（`src/lib/dynamic-patterns.ts`）、蓝图节点注册表（`src/lib/blueprint/specs.ts`）、运行时模板三处为据。

## 一、对方结构（映射前必须分清两库）

- **像素工坊 38 款**：纯代码逐像素生成。预设 = 数据表（`presets/builtin_presets.gd`），每款是有序图层列表，图层引用 **11 个可组合模块**（`modules/`）之一；全局参数（画布/帧数/色板/描边/消散）+ 固定后期流水线（色板离散阶映射 → 去孤点 → 描边 → 盒式模糊柔光）。**全部逐帧纯函数**，连粒子都是闭式解析弹道（prepare 期生成出生表，任意时刻闭式解求位，不积分不累积）。
- **经典库 44 款**：旧 Jeff Studio FX 资源（`.tres`），在 3D 场景实例化后录制成 2D 帧。五类图层载体：SHAPE（预绘像素图集帧 + 着色器换色/量化/扇区 discard 裁剪，33 款）、PARTICLES（真 GPU 粒子模拟，31 款，**全仓唯一大面积有状态部分**）、FIELD（解析场：雨/萤火/涟漪，样本表纯函数）、PROCEDURAL（CPU 像素网格按绝对相位重绘，9 款）、MISSILE（完整投射物子系统，**44 款中实际使用者为 0**）。
- 许可证：代码 MIT、插件原创美术 CC0——引用其帧美术与参数配方无授权障碍（演示工程的第三方角色素材除外）。

## 二、判定标尺

- **已有**：现有图案段或蓝图算子直接对应，参数面对得上。
- **可组合**：多段/多算子/多实例叠加即可，零新代码（给出配方）。
- **可变相**：无直接对应，但换一种机制可达近似观感（差异注明）。
- **可加入**：适合沉淀为库内新模板/新条目，或现有段内的参数级扩展——不需要新引擎原语。
- **需新算子/子模式**：现有段与算子承载不了，要新开发（注明设想与归属线）。

我方口径前提：动态图案与运行时均为**逐帧纯函数**（确定性种子、可任意 seek）。与 D6 立项的关系：有状态模拟与此口径冲突——本盘点中对方唯一有状态的经典 PARTICLES，在我方有闭式发射段对应，不构成引入状态模拟的理由。

## 三、总览结论

1. **像素工坊与动态图案是同一种架构**：数据表预设 = 生成模块组合 + 全局参数 + 后期，且同为逐帧纯函数。其 38 款无一与我方口径冲突。真正的差距在生成器清单：我方多追随/残影/自旋/位移波四种「依附精灵的动态」，对方多光束/团块/火舌/法阵/环带五种「独立几何生成器」。
2. **逐款判定总计（82 款，主判定）**：已有 3 · 可组合 35 · 可变相 38 · 需新算子 6（均为经典 PROCEDURAL 专职绘制款）。「可加入」不占逐款主判定——它是对组合配方的沉淀建议，单列第五节清单。
3. **经典库主体（SHAPE 33 款）不是「图案」而是帧美术**：本产品本身就是精灵/木偶系统，载体天然已有；映射问题不在能力而在内容（引入其 CC0 帧图，或用我方程序段近似重建）。
4. **落雷三机制对照**：工坊 bolt = 中点位移折线（与我方弧线段同路线，真几何生成）；经典 xianxia_lightning 靠着色器扇区 discard 裁分叉（假分叉）；经典 xianxia_arc 是 CPU 像素程序电弧。我方弧线段对齐的是三者中最强的路线，且已有双锚点（arcTarget）、藤蔓、星座连线三模式（D4 已落地）。
5. **MISSILE 子系统不建议跟进**：原仓完整实现却零预设使用；其「路径+命中事件」属编排/玩法层而非图案层。
6. 对方后期链的「像素味」（色板硬阶量化 + Bayer 抖动 + alpha 分级）我方有等价算子（color_lut / dither），但只在蓝图链、不在动态图案主线——是否提为图案级全局后期，见可加入清单。

|---|---|---|

| bolt 闪电（中点位移折线+分支+闪烁） | **已有** | 弧线段（arcMode=arc，分支/闪烁/生长/种子参数齐全，另有双锚点与 vine/stars 两模式） |
| particles 闭式弹道粒子 | **已有** | 发射段同为闭式确定性粒子（轮廓/内部/标记发射源、方向/散布/浮力/湍流/尺寸坡道/前后层）。差异三项——粒子形状集、生命期颜色坡道、gather 汇聚模式——均为参数级扩展，见可加入清单 |
| ring 椭圆环带（扩散/收缩/分段环） | **已有（算子层）** | 蓝图 ring_ripple 节点；若要进动态图案主线做「环带段」属可加入（参数化模板），非新原语 |

| orb 弹体（核+晕+拖尾+环绕光点） | **可组合** | 发光段（核+晕）+ 残影段（拖尾）+ 精灵本体；环绕光点无对应，属可加入级参数扩展（发射段环绕模式） |
| streak 流光线（两段胶囊尖线） | **可变相** | 运动模糊算子（motion_blur 带角度）/残影段可近似速度线；精确版是几何线绘，归 D4 几何家族新子模式候选 |
| beam 光束（包络半宽+流动亮条+贴地光斑） | **需新子模式** | 无对应生成器。设想「光束段」：方向+长宽+展开/收起包络+流动条纹，与弧线段同属几何生成家族（D4 延长线）；临时变相 = 发光长条选区+定向粒子流，质量差 |
| blob 团块（多椭圆距离场+烧穿+热度冷却） | **需新子模式** | 粒子是点精灵、无距离场并集，成不了团块轮廓与烧穿。设想「团块段」：种子团块距离场阈值化+热度色阶；变相 = 大尺寸低透明粒子团（烟/爆的观感近似，逐款附录按变相判） |
| flame 火舌（高度场切舌+噪声撕边） | **需新子模式** | 无站立火焰轮廓生成器。设想「火焰段」：基线+火舌数+上滚噪声，与团块段共享噪声/色阶基建；变相 = 上升粒子+发光（现有「火焰环绕」即此路） |
| glyph 法阵（同心圆+星形连线+刻度+符文） | **需新子模式** | 矢量线绘+逐笔出现动画无对应。归 D4 几何家族（星座连线是同族技术）；变相 = 法阵烘成精灵 + 自旋段 + 发光脉冲，今天完全可做（magic_circle 即按变相判） |

后期与全局：色板量化 → **已有**（color_lut 算子；19 色板主题化属可加入的工程级设置）；描边（外/内/选择性）→ **已有**（outline / outline_emphasis 算子与主渲染描边）；消散四式（抖动/收缩/变暗/淡) → **可组合**（dither 算子+gate、shatter_dissolve、alpha 包络）；soft 柔光 → **已有**（bloom 算子同类）；去孤点 cleanup → **可加入**（小算子，蓝图链一行节点）；停顿帧 hold → **已有**（表演时序与 hold 节点）；方向/翻转/种子/原点/循环 → **已有**（朝向系统、facingAngle、arcSeed 与确定性种子、表演循环）。

## 六、可加入清单（不需要新原语，建议沉淀）

1. **组合配方模板入库**（把附录中「可组合」的高频配方做成内置模板，与现有 9 款同级）：火焰斩、寒冰斩、暗影斩（刀光+残影）、重击、暴击、落雷（环+弧线+爆射）、地面冲击波、治疗、增益光环、拾取闪光、冲刺残影、落地尘土、水花。
2. **发射段参数扩展三项**：gather 汇聚模式（蓄力/虹流的签名动作，反向初速即可，不破纯函数口径）；生命期颜色坡道（起色→终色，经典 PARTICLES 的 4 点坡道可简化为 2~3 点）；粒子形状集（圆点之外加星/菱/短线——其 9 形中取常用者，形状只影响绘制不影响弹道）。
3. **发射段环绕模式**：orb 的 orbiters、护盾流光环——绕宿主椭圆轨道的光点，闭式可算（相位+半径+圈数），与 gather 同批。
4. **环带段模板化**：ring_ripple 算子已有，把扩散/收缩/分段环包成动态图案「环带」预设族（重击环、冲击波环、护盾环共用）。
5. **图案级全局后期**：把蓝图链的 color_lut + dither 提为动态图案的全局后期选项（色板主题 + alpha 分级 + 抖动消散），复刻对方「像素味」的成本最低点。
6. **cleanup 小算子**：去孤立像素/小碎块，蓝图链补一个节点（对方后期固定步，我方像素链缺此步）。

## 十、口径与边界（本研究的未验证项）

- 逐款判定基于双方实现级盘点（对方代码 + 我方参数面/注册表），未做逐款实机对照渲染；「近似」程度（尤其团块/火舌的粒子变相、帧引入的美术风格差）需在真要引入时逐款验。
- 对方经典库帧图为 3D 场景录制，视角/光照与本产品 2D 木偶口径不同，帧引入前需过一遍风格筛选，本研究未逐图审。
- 本研究只做映射与立项建议，不含实现排期；六、七两节的条目是否立项、按何序，等用户拍板。
