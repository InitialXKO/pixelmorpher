# 刀光 vs XSXB 拖尾：比较研究与借鉴裁决

研究问题：本项目刀光（参数扇面）与 [XSXB-Frame-Tuner](https://github.com/sparklecatta-lang/XSXB-Frame-Tuner) 的攻击拖尾（手绘轨迹 + 逐帧开窗）两种做法逐项比较，裁决哪些值得借鉴、哪些不借、哪些我们已有更强解。

方法：两边全链静态通读（数据模型 → 编辑面 → 生成/渲染 → 播放时序），每条结论带文件证据；承重结论（对方窗口模式的切换语义、头部阶跃）由主会话亲读对方代码复核。对方 Godot 运行时只读代码未实跑；本项目侧为盘点既有实现，未改任何产品代码。

---

## 一、先说清一个前提：两边服务的对象不同

XSXB 是**序列帧**角色的调参台：角色动作是画死的帧图，武器在帧与帧之间去了哪儿，系统无从知道——轨迹只能由作者手绘补出来。它的整套设计（手绘棍子轨迹、逐帧开窗、头部在关键帧之间阶跃）都是被「帧图不可动、轨迹无来源」逼出来的解法。

pixelmorpher 是**骨骼/木偶**系统：锚点节点每一帧的真实位姿系统都知道。比较必须站在这条差异上——对方有几件东西看着先进，其实是帧动画语境的补偿；我们若照搬，等于把自己有而对方没有的信息（节点真实运动）扔掉。

## 二、两边模型速览

| | 本项目刀光 | XSXB 拖尾 |
|---|---|---|
| 轨迹来源 | 无轨迹：锚点定格位姿 + 椭圆扇参数（起止角/扫角/半径/扫向）凭参数生成 | 作者用「棍子」（带两端点的线段）逐根摆出的手绘轨迹，绑在动作组上 |
| 形状生成 | `generateSlashFrame` 逐像素现算扇形带（内界由厚度 × 角向收尖因子决定，尾部收尖成刃形），离散 frameCount 张帧瓦片 | 轨迹中心线两侧按棍长成带，Hermite 插值出姿态，规则网格（列 = 细腻度 ×2、行 17）贴纹理 |
| 时间模型 | 进度 p 线性映射片段窗/表演时长，头尾窗公式（头部先展开、尾部后收）随 p 推进 | 两套并存：无逐帧切片时走生命周期（总时长 + 尾/头速度比，头部在头部帧之间**阶跃**、尾部连续追赶）；一旦存了逐帧切片，整段切为窗口模式（见下） |
| 逐帧控制 | 无：帧由公式从规格生成 | `frameSlices[帧] = {tailProgress, headProgress}`（全路径弧长比例）：该帧只显示这一截静态带，帧间不插值，作者逐帧拖头尾把手钉死 |
| 着色 | 程序化色带：调色板沿径向（外弧白黄→内界橙红）+ 径向/角向亮度公式 + 外延辉光，无纹理资产 | 灰度笔刷纹理 × 着色模式（单色/横贯宽度的渐变/原色）+ 三层材质（条纹/破碎/亮核）+ 辉光模糊，重型纹理体系（21 张内置笔刷） |
| 图层 | **恒在最上层，无任何层级参数**，编辑器与包内都是最后绘制盖住角色 | 段级缺省 + **逐棍独立前后层**，渲染按采样时刻逐三角分层，跨界三角双画堵缝，拖尾可中途从角色身后穿到身前 |
| 多重性 | 单个片段/表演恒只解析出一把刀光；多个表演同时激活可各出一把 | 一个动作可挂多段互不相关的拖尾 |
| 编辑面 | 数字参数面板 + 预设按钮 + 预览图（锚点红十字）；**主画布上无手柄、不能手绘、不能拖形** | 画布直操：拖棍子端点/中心/方向箭头（方向 + 切线强度）、一键 Chaikin 平滑、逐帧拖头尾把手开窗 |
| 预设/共享 | **共享定义活引用**：`character.slashDefs` 一处定义、片段/表演按 id 绑定，改定义三路同变；解绑 = 物化 | 拷贝式预设：只存样式键（纹理/颜色/宽度/细腻度等），**不存路径、不存时序**（时长/速度比），应用时物化成段 |
| 运行时 | 规格进包、不烘像素，包内孪生公式在图集构建时预生成帧瓦片 | Godot：ArrayMesh 每帧整表重建 + shader 逐像素着色；Unity：只有数据边界、无渲染器 |

## 三、逐项裁决

### 1. 轨迹：不搬手绘棍子；但「轨迹型刀光」值得立项（本研究最大收获）

对方的手绘轨迹是帧动画的必然（轨迹无来源）。我们若纯手绘，是把骨骼系统的信息优势扔掉。但这一项暴露了我们的一个**真缺口**：现行扇面与武器实际挥动完全脱节——锚点只取定格位姿，扇面的位置/幅度/走向全靠手填角度参数，动作改了刀光不跟。

可借的是「轨迹」这个**概念**，落法完全不同：片段窗内锚点（或另选尖端节点）的实际运动路径就是天然轨迹，可自动采样成带。系统里现成的基建都在：节点位姿逐帧可算（刀光自己就在用起始帧的 `computeWorldTransforms`）、点列数据有笔触/节点轨迹两套先例、轨迹采样有 `interpolateTrajectoryPoints`。即：**轨迹型刀光 = 自动采样锚点运动成带（主）+ 可选
