# PixelMorpher 用户指南

欢迎使用 PixelMorpher！本指南将带你从零开始了解如何使用 PixelMorpher 创作高质量的像素动画。

## 1. 基础概念

在深入操作之前，了解以下核心概念至关重要：

*   **项目 (Project)**：包含所有资产、部件和动画的集合。
*   **资产 (Assets)**：导入的原始图像（PNG, JPEG, Aseprite）。
*   **部件 (Part)**：动画的基本单位。它是从资产中拆分出来的独立像素块，可以独立移动、缩放和应用效果。
*   **修改器 (Modifier)**：应用在部件上的动态效果或变换。多个修改器可以堆叠在“修改器栈”中。
*   **动画剪辑 (Animation Clip)**：定义了一段时间内部件和修改器参数的变化。
*   **工作区 (Workspace)**：针对不同任务设计的专用 UI 布局。

## 2. 创作流程

### 第一步：导入资产
1.  点击左侧面板的“资产库” (Asset Library)。
2.  点击“导入”上传你的像素图或 Aseprite 文件。
3.  导入后，资产会显示在库中。你可以双击预览或直接右键将其拆分为部件。

### 第二步：创建部件
*   **手动创建**：在“部件面板”点击 `+` 号，定义尺寸后手动绘制。
*   **自动拆分**：右键资产库中的图像，选择“自动拆分”。引擎会识别非透明区域并将其转换为独立部件。
*   **SAM 智能选区**：使用 AI 工具点击图像中的某个对象，系统会自动精确提取该区域。

### 第三步：应用修改器
1.  在部件列表中选中一个部件。
2.  在“修改器面板”点击“添加修改器”。
3.  选择一个效果（如 `rotate` 或 `wave`）。
4.  调整参数。注意，某些参数旁边的“关键帧图标”表示该参数可以随时间变化。

### 第四步：时间轴编辑
1.  确保下方的时间轴已展开。
2.  将播放头（蓝线）移动到第 0 帧。
3.  点击部件或修改器参数旁的“记录关键帧”按钮。
4.  移动播放头到第 10 帧。
5.  修改参数（例如旋转角度从 0 变为 45）。
6.  再次记录关键帧。点击播放即可看到补间动画。

## 3. 快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 播放/暂停动画 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `V` | 选择工具 |
| `B` | 笔刷工具 |
| `E` | 橡皮擦工具 |
| `G` | 油漆桶工具 |
| `[` / `]` | 调整笔刷大小 |
| `Alt + 滚轮` | 缩放画布 |
| `中键拖拽` | 平移画布 |

## 4. 导出作品

1.  点击顶部工具栏的“导出”按钮。
2.  选择导出格式：
    *   **GIF**：导出循环动画，支持背景透明度。
    *   **Spritesheet**：将动画帧排列成一张大图，适用于游戏引擎。
    *   **PNG 序列**：导出每一帧为独立图像。
3.  配置帧率和比例，点击“开始渲染”。

## 5. 自动保存与恢复

PixelMorpher 会每隔 5 分钟自动将项目状态备份到浏览器的本地存储中。如果你意外刷新或关闭页面，下次打开时会弹出恢复提示。
