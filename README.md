# PixelMorpher — 像素木偶动画编辑器

PixelMorpher 是一套像素角色动画工具：编辑器里搭建骨骼、换装、做动画与特效，再把角色导出为自包含的**运行时包**（单个 HTML，WebGL 播放器），供宿主应用通过 `procRuntime` 接口驱动。

技术栈：Next.js 16 + React 19 + Zustand 5 + TypeScript。核心工作流：**搭建骨骼 → 换装 → 做动画 → 编排行为 → 导出运行时包**。

## 核心心智模型

整个系统只有一套数据模型（`src/lib/unified-types.ts` 为核心），编辑器与运行时包共享同一套概念：

| 概念 | 是什么 |
|---|---|
| **角色（Character）** | 顶层单位：一棵节点树 + 服装集 + 蓝图/行为/表演等挂载数据。运行时包逐角色转换导出。 |
| **节点（Node）** | 骨骼关节与肢段的统一单位，组成角色的树。位姿 = 静态结构（Socket）+ 动态姿态（Transform）两层。 |
| **槽位（Socket）** | 节点上的解剖连接点（`node.sockets`，一节点多槽），存 3D 静态偏移 `offset3D`；子节点以**插头（plug）**对位到槽位。服装件定义（`node.slot`）不是槽位。 |
| **精灵（Sprite）** | 全局精灵表中的像素图，按 ID 引用；有原点（plug）与命名**标记（marks）**、特征点（landmarks）两套附着语义。 |
| **服装集（CostumeSet）** | 一套外观：逐服装槽（服装件 `slotKey`）给出精灵，覆盖 **8 方向 × 变体 × 纬度**三层；当前服装集由 `activeCostumeSetId` 选定。 |
| **方向 / 纬度 / 偏航** | 三个独立的朝向量：离散 8 方向（variantIndex）、俯仰纬度（latitude，−90..90）、连续偏航角（facingAngle，0..360）。 |
| **轨道（tracks）** | 节点逐属性的关键帧通道（x/y/旋转/…），数据结构 `KeyframeTrack` 全仓一份定义；**轨迹（trajectory）**是画布手绘/制导生成的整段路径，与轨道是两种产物（轨迹可烘焙为轨道）。 |
| **输入轨 / 事件轨** | 角色级时间线轨：输入轨喂行为图的宿主变量（moveX/speed01/grounded），事件轨在关键帧帧触发定格/震屏。两者都是编辑器侧数据，不进运行时包（包内用宿主真实输入）。 |
| **修改器（Modifier）** | 挂在节点上的像素/位姿处理单元列表；列表增删改以手术式同步到节点蓝图，不全量重建。 |
| **蓝图（Blueprint）** | 一份声明式图 IR（`BlueprintGraph`）多处挂载：节点蓝图、角色蓝图（整角色后处理）、状态蓝图（服装状态）、行为图、表演图、全局蓝图、IK 蓝图——挂载点即限定词。 |
| **动态模式（DynamicPattern）** | 挂在节点或服装件上的程序化特效（发光/粒子/弧线/置换/残影/形变/图案场/宿主后处理等），编辑器模拟与包内孪生同式求值；模板与条目收在模式库中复用。 |
| **片段（Clip）/ 表演（Performance）** | 片段是时间线上的动画段；表演是作者编排的蓝图驱动动作，进包后由包内状态机调度。**操控**则指直接拖动节点录制关键帧的操作方式，与表演是两回事。 |
| **行为（Behavior）/ 状态机 / 行为树** | 行为图逐帧求值驱动位姿（输入来自宿主变量）；状态机是包内的身体状态规格（随包）；行为树是宿主侧的大脑，不进包、只输出意图。 |
| **刀光（Slash）** | 角色级共享定义（`slashDefs`）一处存，片段与表演以 ID 活引用；解绑即物化为私有副本。 |
| **运行时包（Runtime Package）** | convert 把角色展开/烘焙而成的自包含产物：精灵图集、动画曲线、动态模式孪生、状态机、D6 有状态模拟（链摆/布料/粒子模拟）。不能进包的数据（蓝图接线、输入轨、事件轨等）按口径在导出时点名警告，不静默丢失。 |

渲染只有一条管线：`unified-render`（世界变换合成 → 精灵解析 → 部件像素定稿 → 合成出图），主画布、拾取编号图、覆盖层共用同一份世界变换。

## 功能地图

- **搭建**：新建向导（模板生成整角色）、节点树编辑、槽位编辑、2D 拆分（参考图/精灵按骨骼链切分建节点）、伪 3D 转面与比例标尺、精灵编辑（画笔/选区/标记/特征点/修复/参考图装配）。
- **换装**：服装集管理、逐槽指派、8 方向与变体/纬度分层、镜像映射。
- **动画**：关键帧轨道、手绘轨迹与制导生成、程序化条目（弹簧/噪声/公式等）、IK（拖拽求解与烘焙为蓝图）、预设步态、刀光编排。
- **编排**：蓝图编辑器（节点图 + 参数接线覆盖 + 时序编排 cue）、行为图与宿主变量、表演、状态机/行为树编排。
- **特效**：动态模式（模式库）、效果轨（画布级逐帧效果与飘字）、画布修改器轨、全局修改器、特效笔（模糊/辉光/粒子/残影）。
- **时间线**：播放调度（片段窗/循环）、输入轨、事件轨、效果轨与节点轨道的统一编辑面。
- **导出**：运行时包（HTML），导出选项含插件链处理（drop/bake/live）、逐帧修正范围、IK 处理三样显式开关。

## 开发与验证

```bash
npm install
npm run dev        # http://localhost:3000
npx tsc --noEmit   # 类型检查
npm run build      # 生产构建（构建通过才是「干净」的门）
```

`scripts/verify-*.mts` 是回归探针集（`bun scripts/verify-<name>.mts`）：每支针对一个机制的可证伪断言——探针能证明错误存在与防已知回归，不能替代读代码推导正确性。自动保存走 OPFS + IndexedDB，旧工程数据在载入时走迁移链规范化。
